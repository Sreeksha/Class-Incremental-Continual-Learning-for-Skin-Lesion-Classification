This project implements a Class Incremental Continual Learning (CICL) system for skin lesion classification using DenseNet201. The system addresses catastrophic 
forgetting when new lesion types are introduced incrementally. The project applies CICL strategies (replay, regularization, and knowledge distillation) to enable the 
model to learn new skin lesion classes without forgetting previously learned classes. It uses the HAM10000 and ISIC 2019 datasets.
